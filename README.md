# LauncherCraft 🛠️

> 一个纯由个人独立开发的 2D 沙盒游戏（Minecraft 风格）。
> 诞生于 2026 年某次魔幻的“举报风波”——
> 某家长因为孩子在Minecraft私服充钱，
> 家长直接把PCL（Plain Craft Launcher）
> 连同私服房主一同举报，
> PCL被迫关闭Minecraft下载功能。
>编程语言：Kotlin
