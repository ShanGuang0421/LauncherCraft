# LauncherCraft 🛠️

> **一个纯由个人独立开发的 2D 沙盒游戏（Minecraft 风格）。**
> 诞生于 2026 年某次魔幻的“举报风波”——某家长因为孩子在 Minecraft 私服充钱，直接将 PCL（Plain Craft Launcher）连同私服房主一同举报，PCL 被迫关闭了 Minecraft 的下载功能。
> 
> **编程语言**：Kotlin

> **A 2D sandbox game (Minecraft style) independently developed by a single developer.**
> Born from a bizarre "reporting turmoil" in 2026: A parent, upon discovering their child spent money on a Minecraft private server, reported both the server owner and PCL (Plain Craft Launcher). As a result, PCL was forced to remove its Minecraft download feature.
> 
> **Programming Language**: Kotlin
